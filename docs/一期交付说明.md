## 3.1 感知层

### FE-01 数学公式渲染（P0）
- 实现：`webview-editor/src/preview.ts` 自定义 marked 行内/块级扩展，KaTeX（npm 打包，无 CDN）`renderToString` 渲染；行内公式带 `$5/$10` 货币误判防护（首尾空白与数字边界检查）；非法公式渲染为 `.math-error` 错误提示而非崩溃。KaTeX CSS 在 `build.mjs` 中内联进 `assets/editor.html`（woff2 字体 base64，woff/ttf 剔除）。
- 验证：`webview-editor/test/preview.test.mjs`（行内/块级/错误/货币防误判四断言）；示例笔记冒烟（含分数、求和、矩阵）。

### FE-02 Mermaid 图表（P0）
- 实现：marked 代码块渲染器对 ` ```mermaid ` 输出占位 `<div class="mermaid-src">`；预览阶段 `enhanceMermaid` 懒加载 `import('mermaid')`（首次进预览才加载，符合 §7.2 缓解项）后 `mermaid.render` 异步渲染，主题深浅自动映射 dark/default，渲染失败显示 `.mermaid-error` 错误框不崩溃。导出复用同一管线，SVG 内嵌进导出文档。
- 验证：预览测试（占位符与源码收集断言）+ 示例笔记冒烟（流程图/时序图/饼图三源断言）。真机视觉验证待 Expo Go 冒烟。

### FE-03 脚注/高亮/[TOC]（P1）
- 实现：`==高亮==` 走 marked inline 扩展 + inlineTokens 解析；`[TOC]` 为块级扩展，渲染后以标题树回填锚点链接；GFM 脚注因 marked 15 无内置支持，自行实现「行内引用 + 块级定义」两个扩展（引用渲染为 `<sup>` 反向锚点，定义汇总到底部 `.footnotes` 区，缩进 ≥4 空格为多行定义）。标题渲染器为每个标题生成保留汉字的 slug id。
- 验证：预览测试（mark/TOC 展开与锚点/h1 id/脚注区四断言）。

### FE-04 YAML Front Matter（P1）
- 实现：`src/storage/frontMatter.ts` 扁平解析（title/tags/date 等），标签支持 `[a, b]` / `#tag` 两种写法；列表卡片与编辑页头部显示 tags 芯片与日期；保存走整文件原样写回（未识别字段保留在 front matter 块内不破坏）；预览渲染时剥离 front matter（`preview.ts stripFrontMatter`，避免被解析成 setext 标题）。
- 验证：`test/unit.test.mjs`（标题/标签/日期/正文剥离/无 front matter/仅 front matter 六断言）+ 预览测试（元数据不进正文断言）。

### FE-05 大纲面板（P0）
- 实现：WebView 在每次变更事件中上报标题树（`collectHeadings`，跳过代码围栏内 # 行）；`OutlinePanel.tsx` 侧栏三页签（大纲/反链/历史）；点击标题经桥接 `scrollTo` 命令把光标落位到行首并 `EditorView.scrollIntoView(pos, {y:'center'})` 滚动到屏幕中部；当前光标所在标题高亮。
- 验证：桥接命令类型双端同步（protocol 两份文件代码一致）；真机交互验证待 Expo Go 冒烟。

### FE-06 全文搜索（P0）
- 实现：`workspaceRepo.searchNotes` 全库读文件内存匹配，命中笔记展示至多 3 行片段（截断至 64 字符）的搜索结果卡片；250ms 防抖；编辑器 ⌘⇧F 全库搜索经全局命令桥接回列表页并自动聚焦搜索框。
- 验证：真机验证待 Expo Go 冒烟（标题/标签/正文三类关键词）。

### FE-07 子文件夹/文件树（P1）
- 实现：`listWorkspace` 递归遍历（跳过 `history`、`assets`、`.trash` 保留目录）；列表页面包屑导航（根 › a › b）+ 子文件夹卡片（含笔记计数）；文件操作（新建/重命名/删除/跨文件夹移动）见 WS-02。`NoteMeta` 增加 dir/relPath 字段。

### FE-08 Wiki 链接 + 反链（P2）
